description: Public Utilities Interim Rate Increase (Decrease) Percentage indicates
  the percentage of an interim rate increase or decrease that a public utility is
  permitted while waiting for a final regulatory decision. This measure provides context
  for the temporary financial adjustments sought by utilities, distinguishing it from
  absolute dollar amounts that do not convey the relative impact. The value is reported
  as a percentage and reflects the duration of the interim request.
