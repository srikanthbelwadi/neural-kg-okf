description: This measure indicates the amount of liability for a conversion option
  that has been reclassified to stockholders' equity when the embedded option no longer
  requires separation from the host instrument. It specifically pertains to embedded
  derivatives, which are financial instruments that include features that can affect
  their value. This measure is distinct from other equity-related metrics as it focuses
  on the reclassification of embedded derivatives rather than general equity changes.
  The value is reported in currency.
