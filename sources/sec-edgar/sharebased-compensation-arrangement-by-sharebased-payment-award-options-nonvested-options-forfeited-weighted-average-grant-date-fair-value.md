  Nonvested Options Forfeited, Weighted Average Grant Date Fair Value — SEC EDGAR
description: This measure indicates the weighted average grant-date fair value of
  non-vested options that have been forfeited for a publicly traded company or SEC
  filer. It reflects the average value of options that were granted but subsequently
  forfeited before vesting, weighted by the number of options forfeited. This measure
  is distinct from those that report on total options or vested options, as it specifically
  addresses the fair value of forfeited non-vested options. The value is reported
  on a per-share basis.
